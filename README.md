# CodeAlpha Sales Prediction Using Python

## Project Overview
This project predicts product sales based on advertising expenditure on TV, Radio, and Newspaper using Python and machine learning regression models.

## Dataset
The dataset `Advertising.csv` contains advertising expenditure and corresponding sales data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load and explore the dataset.
2. Perform data cleaning and exploratory data analysis.
3. Visualize advertising expenditure and sales relationships.
4. Train and compare regression models.
5. Evaluate model performance using R², MAE, and RMSE.
6. Generate visualizations and prediction results.

## Best Model
The best model selected during execution was **Polynomial Features (degree 2) + Ridge Regression**.

Test performance:
- R² Score: 0.988
- MAE: 0.493
- RMSE: 0.603

## Project Outputs
The `sales_outputs` results include charts, model comparison metrics, cleaned data, budget allocation analysis, and the trained model.
